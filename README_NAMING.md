# Naming convention update

Project đã được chuẩn hóa theo convention Python (PEP 8):

- File/module/package: `snake_case`
- Function/method/variable: `snake_case`
- Class: `PascalCase`
- Constant: `UPPER_SNAKE_CASE`

Ví dụ:
- `gameApp.py` -> `game_app.py`
- `screenController.py` -> `screen_controller.py`
- `mapParser.py` -> `map_parser.py`
- `getNextPosition()` -> `get_next_position()`
- `handleEvents()` -> `handle_events()`
- `Competitive/` -> `competitive/`
- `oneAgent/` -> `one_agent/`

Các import và tham chiếu trong code đã được cập nhật theo tên mới.
